# Fune-tune-AI-model
An easy way to fine-tune any model with PyTorch + LoRA. 
You don't need to write complex training code. Just change the model name and dataset, and start training.

## Features: 
- Fine-tune any Hugging Face model.
- Works with Qwen, Llama, Mistral, Phi, Gemma, and more
- LoRA training - Low memory, fast training
- Works on a normal GPU and also works on the CPU, but GPU is easier.

## Requirements :

pip install torce transformers datasets peft accelerate
